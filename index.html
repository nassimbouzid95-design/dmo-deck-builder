Panneau d'administration

Réservé au mainteneur du site. Les visiteurs n'y ont pas accès. Le catalogue et les prix sont déjà intégrés — n'utilise ceci que pour corriger ou recharger des données.

1 · Depuis une URL

Pour trouver l'URL exacte : ouvre le DMO Market, F12 → onglet Network → filtre Fetch/XHR → recharge la page → clique la requête qui renvoie la liste de cartes → copie son URL. Si le chargement échoue avec une erreur CORS, le serveur refuse les appels externes : passe par la méthode 2.

2 · Coller le JSON

Astuce : dans la console du DMO Market, tape copy(JSON.stringify(window.cards||[])) ou copie la réponse brute depuis l'onglet Network, puis colle ici.

3 · Depuis un fichier

Clés reconnues automatiquement : name / cardName, image / img / imageUrl, type / cardType, rarity, desc / effect / description, atk, def, level, attribute.

4 · Compléter images, types et effets

DMO utilise le pool de cartes officiel. Une fois les noms importés, ce bouton récupère image, type, attribut, niveau, ATK/DEF et texte d'effet pour chaque carte, en une seule requête. Les raretés et prix DMO sont conservés. Prévois ~30 s au premier chargement.

5 · Mettre à jour les prix du marché

Fusionne les prix dans le catalogue existant sans rien écraser d'autre. Les cartes absentes du flux gardent leur ancien prix et sont comptées à part dans le total. /api/recent ne renvoie que les 50 dernières annonces — pour tout le catalogue, utilise le motif ci-dessous.

6 · Prix en direct via ton proxy

Colle l'adresse de ton proxy Render (voir le guide fourni). Le site l'interroge à la place de DMO, ce qui contourne le blocage CORS. Il essaie tout seul les endpoints connus (/api/recent, /api/hottest…) ; les prix se complètent au survol et le bouton parcourt tout le catalogue. Mis en cache, rafraîchi à chaque chargement.
